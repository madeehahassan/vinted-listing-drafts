# Prepare Vinted listings

Work from the folder the seller names. Ask for the selling country, currency, listing language and pricing preferences only if they are missing and materially affect the listings. Read [the record format](references/record-format.md) before creating records. Keep all files and review data local unless the seller has named an existing review destination and authorized using it.

## Inventory and photographs

1. Account for every source file. Remove byte-identical duplicates from the working set. Group photos by the product they actually show, not filename alone. Hold unrelated media and private number or inventory tags outside listing photo sets.
2. Read visible labels and packaging for brand, model or style code, size, material, colour and quantity. Record what each photo proves. Mark condition, authenticity and any unreadable detail for the seller to confirm. A clean-looking item does not prove that it is new or unworn.
3. Preserve originals. Convert unsupported working images, including HEIC, to full-size, correctly oriented JPEGs. Check each conversion and its item mapping. Improve exposure, crop and background only where useful. Keep label and flaw close-ups faithful to the source. Compare edited images with originals at full size; reject edits that alter colour, texture, seams, hardware, silhouette, wear or garment edges. Keep original and accepted edits together, and let the seller discard or restore any photo.

## Research and draft

4. Search each identifiable product using its brand plus photographed details, style code and image search when available. Open candidate pages and compare decisive visual details. Link each direct source and classify it as an exact match, likely same design or similar item. Explain what is unverified if no exact match exists.
5. Keep original retail, current new sale, live resale asks and completed resale sales as separate price observations with currency, date, condition and match quality. A live asking price is not a completed sale. Suggest a resale asking price from the strongest relevant evidence and the seller's stated margin or negotiation preference. If the seller provides no margin, give a reasoned price range and editable asking price rather than inventing a fixed markup. Mark weak estimates as provisional. Preserve any price the seller edits.
6. Create one buyer-facing listing per product in the requested language. Use only supported claims. Put missing size, condition, authenticity, quantity and price evidence in private review flags. Choose concise, item-specific titles and descriptions.

## Review handoff

Use the seller's existing review desk if one is available. Otherwise create a local editable review file or page appropriate to the host's tools. Show each item's selected JPEGs in listing order and label them with JPEG filenames. Keep discarded photos available to restore. Show rejected edits, title, description, Vinted category, condition choices, size, asking price, comparable links and exact review questions. Leave an unverified condition unselected. Separate approval to save a Vinted draft from approval to publish. Save seller edits before moving between items and verify that they survive reopening the review file or page. Test that every image opens and that discarding and restoring a photo updates the selected export set.

Report the number of products found, selected photos, rejected edits and records needing factual checks. Ask the seller to approve named items for draft transfer or publication only after the review material is complete. The preparation step never uploads listing photos to Vinted.
