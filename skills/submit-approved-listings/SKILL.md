# Submit approved Vinted listings

Read the seller's current review records immediately before transfer. Work only on the named items whose approval state or direct message authorizes the requested action. Approval for a Vinted draft permits saving a draft. Publication requires the seller's explicit approval for the named items. An explicit publication instruction also permits the draft creation needed to publish them.

Use the host's authorized browser control and the seller's already signed-in Vinted session. Never ask for a password, cookie or raw request header. If browser control is unavailable, give the seller the selected JPEGs and current listing details and state the remaining manual step.

For each approved item:

1. Recheck selected photos, title, description, brand, size, condition, category and price against the current record. Hold a required field that lacks evidence or seller confirmation. If the seller confirms a fit size that differs from a photographed label, use the confirmed Vinted size and disclose the label size in the description.
2. Open Vinted's sell form. Upload only selected listing JPEGs; leave inventory reference photos out. Fill the current record, verify Vinted's suggested brand, category, colour and parcel size, and let dependent fields finish loading before selecting them.
3. Save as draft, then read the saved card or edit page back to check photos, size, condition and price. Mark the record drafted only after that check. Publish only if the specific item has publication approval; verify its public or pending-review state before marking it published.
4. Log the item ID, Vinted URL or draft ID, asking price and result. Keep blocked items on the review desk with the exact reason.

If Vinted presents a fee, a paid promotion, a new rule or a required fact that changes an approved listing, pause that item and get the seller's decision. Do not change another public listing without a direct request. Report drafted, published and blocked counts separately with direct links where available.
